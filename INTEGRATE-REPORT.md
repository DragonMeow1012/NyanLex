## 5. Not done / caveats
- R2 (see above); pure-token colour-pair removal; lead icon after a row break; no real game launch (all UI/hook changes are compile + unit tested only).
- Hub-shared / existing caches: units whose key began with a decorative icon (and 3+ words) get a new key (one-time re-translation; hub rows for those units no longer match).
- `hook-guards.py check` reports DRIFT right after a fresh checkout on Windows because the generated `NyanslateHooks.java` files are written with LF while `core.autocrlf=true` checks them out as CRLF; after `hook-guards.py apply` the content is byte-identical (git sees no change) and `check` is OK.
- Do not use `git stash` in this repository: its stash list holds two old unrelated entries (pre-1.0.2 rollback, skeleton-cache v1) which `git stash pop` applies. One accidental pop on a clean tree conflicted and was fully reverted (`reset --hard` + deleting the two untracked `com/dragonmeow` directories it created); nothing from it was committed.
