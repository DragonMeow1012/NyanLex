Mod の UI は Minecraft クライアントの言語に従い、英語・日本語・繁体字中国語・簡体字中国語に対応します。それ以外では英語 UI を使用します。ゲーム内テキストの翻訳先言語は、この 4 言語に限定されません。

## 導入方法

1. **対応するビルドを選びます。** [ダウンロード](#ダウンロード)から Minecraft のバージョンと Loader に合う単一の JAR を選び、そのインスタンスの `mods` フォルダへ入れます。Fabric では、対応する Fabric API も必要です。
2. **言語とサービスを選びます。** ゲームを起動し、クイック設定で翻訳先の言語と翻訳サービスを選択します。確認するまでオンライン翻訳は有効になりません。
3. **読み始めます。** 新しいバージョンでは、アイテムにカーソルを合わせて <kbd>R</kbd>、表示中の画面や HUD のテキストには <kbd>P</kbd> を押します。<kbd>G</kbd> で原文と翻訳の表示を切り替えます。

| モード | チャット | アイテム、画面、その他の表示領域 |
| --- | --- | --- |
| Google 機械翻訳 | 自動 | `R`／`P` で必要なときに翻訳 |
| AI 翻訳 | 自動 | 自動翻訳。`R`／`P` で強制的に再翻訳 |
| 保存済みの翻訳 | すぐに表示 | 新しいリクエストを送らず、すぐに表示 |

表示領域ごとに、原文のみ、翻訳のみ、または両方を選べます。既存の AI 翻訳が最優先され、その次に翻訳パックと保存済みの機械翻訳が使われます。旧バージョンでは操作が異なるため、[キーボードショートカット](#キーボードショートカット)をご覧ください。

## 対応環境

- Fabric、NeoForge、Forge（Minecraft 1.12.2～26.3）に対応しています。全一覧は[ダウンロード](#ダウンロード)をご覧ください。
- 旧バージョン（Fabric 1.14.4～1.16.5、Forge 1.12.2～1.13.2）は簡易インターフェースです。短いクイック設定、その場で確認するウィンドウ、カテゴリ別の設定画面はありますが、翻訳パックと全コンテンツの事前翻訳には対応していません。
- Mod パックのクエスト／タスクブック画面は、長い段落、色付きテキスト、ツールチップ向けに最適化されています。
- クライアント側だけで動く Mod です。サーバーを変更せず、プレイヤーに代わってチャットを送信することもありません。

## 全コンテンツの事前翻訳

**翻訳設定 → 自分の翻訳**を開き、右側の**カテゴリ**を展開します。初期状態では「アイテム名と説明」と「画面テキスト」の両方が選択されています。クエストのタイトルと説明は画面テキストに含まれます。「開始」または「続行」を押したときだけ実行され、既存の翻訳はスキップします。一時停止、再開、停止もできます。AI 翻訳が必要で、オンライン翻訳が無効の場合は先に確認します。一部の画面コンテンツはワールドに入った後で読み込まれるため、そのコンテンツを事前翻訳する場合は先にワールドへ入ってください。

レート制限で一時停止した場合は手動で再開できます。モデルを変更すると、新しいモデルの状態を確認します。Google の 429 エラー時の一時停止とバックオフ保護も引き続き有効です。

## 翻訳パックと共有

翻訳パックには、メンテナーが準備して GitHub で公開している AI 翻訳が収録されています。Mod の起動時に自動確認することはありません。入手方法は二つあります。クイック設定の最終ページで自動検出する方法（インストール済み Mod に対応するパックが見つかった場合のみ表示）と、翻訳設定 → 翻訳パックの「翻訳パックを検出してダウンロード」ボタンを使う方法です。どちらも各パックのサイズと合計予定サイズを表示し、確認後にだけダウンロードして保存済み翻訳へ統合します。同じカテゴリの「ダウンロードした翻訳パックを消去」は、パック由来の翻訳だけを削除し、自分で作成した翻訳は残します。読み取るのはハブの `index.json` と、確認したファイルだけです。ローカルの情報をアップロードすることはありません。パックには翻訳文とハッシュだけが含まれ、原文は含まれません。ライセンスは CC BY-NC-SA 4.0 です。詳細は [translation-hub/README.md](translation-hub/README.md) をご覧ください。

### 翻訳を共有する

翻訳設定の「翻訳をエクスポート」を使い、生成された JSON を友達へ送ります。**自動分割エクスポートと複数ファイルの一括インポートに対応しています。** 小さなエクスポートは一つの JSON になり、上限を超えると `translations.part-0001.json`、`translations.part-0002.json` のように自動分割されます。同じ一式をまとめて共有してください。受け取った側は同じ翻訳先言語を選び、「翻訳をインポート」で Ctrl／Shift を使って複数の JSON を選択します。有効で不足している翻訳だけを統合し、既存の翻訳は保持します。翻訳リクエストも送信しません。ファイルには翻訳データだけが含まれ、API キー、ログイン情報、設定は含まれません。

<details>
<summary>形式の互換性、分割ファイル、インポート上限</summary>

Fabric 1.17 以降と NeoForge は同じ形式を共有できます。Fabric 1.14.4～1.16.5 と Forge 1.12.2～1.13.2 は旧形式を共有できます。この二つの形式間ではインポートできません。各ファイルの上限は 32 MiB、100,000 件です。これはエクスポート全体の上限ではなく、超えると自動で分割されます。従来の単一ファイルも引き続き利用できます。上限を超えた古い JSON は、キャッシュを持つクライアントから再度エクスポートしてください。

複数ファイルはファイル名順に処理し、最初に読み込まれた有効な翻訳を優先します。破損、非互換、容量超過のファイルがあっても、ほかのファイルは処理を続けます。完了メッセージには追加件数、成功数／総ファイル数、失敗情報が表示されます。正常に取り込まれた内容はロールバックしません。エクスポートで既存ファイルを上書きすることはないため、同名ファイルがある場合は別の名前を選んでください。

旧クライアントの共有キャッシュ上限は 8,192 件のままです。ファイルを追加すると残り容量を超える場合、そのファイルを拒否して既存の翻訳を守ります。新しいクライアントのディスクキャッシュは、初期設定で各 100,000 件まで保持します。上限を超えると既存のキャッシュ方針に従って古い項目を削除します。エクスポートの分割によって、ゲーム側のキャッシュ容量が増えることはありません。

</details>

## キーボードショートカット

Fabric 1.17 以降と NeoForge：

| キー | 動作 |
| --- | --- |
| `G` | 原文／翻訳表示を切り替える |
| `R` | カーソル下のアイテムを翻訳／再翻訳する |
| `P` | 現在の画面に見えているテキストとツールチップを翻訳／再翻訳する |
| 未割り当て | 翻訳設定を開く |

旧バージョンの UI：

| 対象 | キー |
| --- | --- |
| Fabric 1.14.4～1.16.5 | `G` で翻訳設定を開く。`P` で現在の画面を再翻訳する |
| Forge 1.12.2～1.13.2 | `G` で翻訳設定を開く。`H` で翻訳を有効／無効にする。`P` で現在の画面を再翻訳する |

`P` は、カーソルを合わせたツールチップを含む、現在見えているテキストを取得します。画面を開いていない場合は、表示中の HUD テキスト（スコアボード、ボスバー、タイトル、アクションバー、ネームタグ）を取得します。画面外のコンテンツは読み取らず、文字入力中には動作しません。機械翻訳ではチャット以外を必要なときに翻訳するため（上の「導入方法」を参照）、`R`／`P` を使って翻訳します。AI では自動翻訳され、`R`／`P` は強制的な再翻訳になります。完了までの時間は翻訳サービスによって異なります。

<details>
<summary>以前のプロジェクト名からの更新：設定、キャッシュ、キー設定の移行</summary>

更新後にキー設定が初期化されたように見える場合：このリリースでは Mod ID が `mctranslator` から `nyanlex` に変更されています。初回起動時に、旧バージョン（さらに以前の名前を含む）の設定ファイル、翻訳キャッシュ、`options.txt` 内のキー設定を新しい名前へ一度だけ自動コピーします。古いファイルは削除しません。新しい名前ですでに翻訳キャッシュが存在する場合は、古いキャッシュを統合し、新しいファイルにある項目を優先します。これも一度だけ行うため、その後に消去したキャッシュが再び戻ることはありません。

</details>

<details>
<summary>その他の設定と翻訳動作</summary>

**チャット入力の翻訳**：「一般」で有効にしてからチャットを開き、下書きを入力します。保存済みの位置がなければ右下に表示され、タイトルバーのドラッグで移動できます。翻訳先は英語が初期設定で、言語名やコードから検索できます。Esc でチャットを閉じても、同じゲームセッション中は下書きが残り、次に開いたときに続きを入力できます。「翻訳して入力」を押した後、チャット欄の翻訳を確認し、Enter キーで送信します。

対応するすべてのバージョンで、ChatGPT／Codex へのログイン、モデルと推論レベルの選択、セッションのトークン表示を利用できます。初期設定は `gpt-5.6-terra`／`medium` です。

非同期バッチ、優先度付きキュー、ディスクキャッシュ、失敗時のバックオフにより、メインスレッドの処理と重複リクエストを減らします。送信間隔と収集時間はどちらも初期値が 5 秒で、無効または 1～10 秒の合計 11 段階から選べます。

プレイヤー名は TAB リストを基にローカルでマスクします。新しいバージョンでは、既知の Mod、シェーダー、技術名とそのバージョン番号だけで構成されるラベルを翻訳対象から外します。既存の翻訳は引き続き優先されます。

**ツールチップのセグメント別キャッシュ**：長いツールチップ（タイトルと複数行の本文）をセグメントごとに保存・復元するため、実際に変わった部分だけを再翻訳します。

**設定画面は七つのカテゴリに分類**（Esc → 設定 → 翻訳設定…）：一般、表示、翻訳サービス、翻訳パック、自分の翻訳、詳細設定、NyanLex について。検索ボックスとゲーム内マニュアルもあります。「一般」からクイック設定をいつでも再実行できます。「翻訳しない語句」では、サーバー名やブランド名を原文のまま保持できます（大文字と小文字を区別しない単語単位の一致）。

</details>

## プライバシー

- **新規インストールでは「オンライン翻訳」は初期状態で無効です。** 無効な間は、どの翻訳サービスにもテキストを送信しません。
- 有効にする方法は三つあります。初めてタイトル画面を開くと自動的に表示されるクイック設定で、機械翻訳、AI 翻訳、または「後で」を選びます。「完了」を押すまでは設定を適用せず、何も送信しません。オンライン翻訳が無効な状態でアイテム翻訳キー（初期値 `R`）または画面翻訳キー（初期値 `P`) を押すと、確認画面が開きます。「翻訳を開始」を押すまで送信しません。翻訳設定 → 一般の「オンライン翻訳」から直接有効にすることもできます。
- 有効にしなくても利用でき、何も送信しないもの：ローカルキャッシュ内の既存翻訳、ダウンロード済みの翻訳パック、内蔵用語集、Minecraft 自体の言語ファイルにあるバニラテキスト。
- 有効にすると、翻訳対象として設定したテキスト（アイテムの説明、画面など）を送信します。チャット翻訳を有効にした場合、**個人メッセージを含む**チャット内容も送信されます。
- チャット入力翻訳は、「翻訳して入力」を押したとき（またはフローティングウィンドウで Enter を押したとき）だけ下書きを送信します。チャットを閉じた後の下書きはメモリ内だけに保持し、ゲーム終了後は残りません。翻訳キャッシュやエクスポートファイルにも保存しません。入力後も、実際に送信するかどうかは自分で確認できます。
- テキストは、選択した翻訳サービスへ送信されます。
  - **機械翻訳（Google、キー不要）**は**非公式**のウェブエンドポイントを使用するため、いつでも制限されたり利用できなくなったりする可能性があります。
  - **AI エンジン**（Gemini、OpenAI、DeepSeek などの OpenAI 互換サービス、または ChatGPT／Codex ログイン）は、自分のキーまたはログインを使い、自分で設定したサービスにだけ送信します。ChatGPT でログインした場合は、アカウントの Codex 利用枠を使用します。
- **API キーはローカルの設定ファイルにだけ保存**され、選択したサービス事業者にだけ送信されます。設定画面では伏せ字で表示し、ログやデバッグファイルには書き込みません。
- 旧バージョンから更新した場合は、以前の設定を引き継ぎます。すでに翻訳を利用していた場合、オンライン翻訳は有効のままです。
- **翻訳パックはダウンロードのみで、アップロードしません。** 検出とダウンロードでは GitHub の公開ファイル（`index.json` と確認したファイル）を読み取るだけです。テキストや Mod 一覧を送信することはなく、確認するまで何もダウンロードしません。
- TAB リストにあるプレイヤー名はローカルで先にマスクします。その他のサーバーテキストには、ユーザーが入力した内容が含まれる場合があります。
