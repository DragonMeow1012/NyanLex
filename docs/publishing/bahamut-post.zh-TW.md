## 正文

【首圖：`docs/brand/nyanlex-banner.svg`】

大家好，我是 NyanLex Translator 的作者。

現在是 AI 快速發展的時代，我們已經可以請 AI 翻譯文章、整理資料，甚至協助寫程式；但回到遊戲裡，語言隔閡往往還是卡在最瑣碎的地方。為了看懂一件裝備或一句任務說明，玩家仍得暫停遊戲、切換視窗、複製文字，再把結果帶回來。工具變聰明了，過程卻不一定真的更順。

我一直覺得，好的工具不該讓玩家多做一套流程，而是安靜地融入原本的遊玩方式。NyanLex 就是從這個想法開始：讓 Google、AI 或本機模型直接協助處理眼前的文字，同時把是否連線、使用哪個服務，以及最後要不要相信或送出譯文的決定留給玩家。

玩國外模組包或多人伺服器時，不知道大家有沒有遇過這些情況：

- 任務書寫了一大段英文，只能一直切出去查翻譯
- 物品能力看不懂，不敢確定這件裝備到底能不能用
- 國外隊友正在聊天，自己跟不上；想回話時又要先開翻譯網站
- 冷門模組沒有繁中語言檔，只能等別人翻譯

所以我做了 **NyanLex Translator**。

它是一個純客戶端的 Minecraft 翻譯模組，可以翻譯聊天、物品名稱與說明、任務文字、書本、介面和部分 HUD；也能讓你直接用中文打草稿，翻成對方的語言後填入聊天欄，由你確認內容再親手送出。

伺服器和一起玩的朋友都不用安裝。

## 一、聊天原文和譯文一起看

【插圖：`docs/images/promo/better-mc-bilingual-chat.png`】

收到外語訊息時，NyanLex 可以保留原文，並把譯文顯示在旁邊。

這樣不只能快速看懂隊友在說什麼，遇到人名、伺服器用語或翻譯不自然時，也還能對照原句，不會只剩下一段不知道原文是什麼的機翻。

聊天以外，物品名稱與說明、任務書、一般介面、書本，以及記分板、Boss Bar、標題、Action Bar、名牌等可見文字也在處理範圍內。

每個區域都能選擇顯示原文、譯文，或兩者並列。

## 二、物品與任務不用一直切出去查

【左右對照插圖：
`docs/images/promo/better-mc-item-original.png`
`docs/images/promo/better-mc-item-translated.png`】

游標移到物品上時，可以翻譯物品名稱與整段提示框。長篇任務說明則會依段落處理，盡量保留原本的換行與文字顏色。

現代版本中：

- 使用 AI 翻譯時，已開啟的翻譯區域可自動處理
- 使用 Google 機器翻譯時，聊天會自動翻譯；物品與介面則由玩家按鍵觸發
- 已經翻過的內容會存進本機快取，下次看到可以直接使用
- 已有的 AI 譯文、翻譯包與本機機翻都能沿用，不必每次重新送出

預設按鍵為：

- `G`：切換原文／譯文
- `R`：翻譯或重新翻譯游標指向的物品
- `P`：翻譯或重新翻譯目前畫面可見的介面、提示框或 HUD

舊版 Minecraft 的按鍵與功能較精簡，完整差異可在 GitHub 說明頁查看。

## 三、用中文打字，再翻成對方的語言

【插圖：`docs/images/promo/better-mc-chat-composer.png`】

這是我自己很想要的一項功能。

開啟聊天後，畫面上會出現一個可以拖曳的小浮窗。你可以直接輸入中文，選擇想翻成的語言，再按下「翻譯並填入」。

譯文只會先填進 Minecraft 原本的聊天欄，不會替你自動送出。你可以先檢查、修改，確定沒問題後再按 Enter。

浮窗會記住位置；閱讀遊戲內容的語言和對外聊天的語言也能分開設定。例如介面翻成繁體中文，但回覆國外隊友時翻成英文。

聊天草稿只有在你主動要求翻譯時才會送出，不會寫進翻譯快取，也不會出現在匯出的翻譯檔裡。

## 四、Google、AI、本機模型都能選

【插圖：`docs/images/promo/better-mc-translation-settings.png`】

NyanLex 沒有把玩家綁在單一翻譯服務上，目前可選：

- Google 機器翻譯：不需 API Key
- Gemini、OpenAI、DeepSeek、OpenRouter
- 其他 OpenAI 相容服務
- Ollama、LM Studio 等本機模型
- ChatGPT／Codex 登入

AI 服務通常需要自己的 API Key；ChatGPT／Codex 模式需先在電腦上安裝 Codex CLI，並使用帳號的 Codex 額度。翻譯速度、品質與可能產生的費用，都取決於你選擇的服務。

如果不想連線，新安裝時可以直接選「先不要」。已有的本機快取、翻譯包與內建譯名仍能離線顯示。

---

## 五、可以先把內容翻好，也可以分享譯文

現代版本提供「全內容預熱」，可以在冒險前先處理物品名稱、說明與介面文字。已有譯文會自動略過，也能隨時暫停、繼續或停止。

另外也支援：

- 下載現成翻譯包
- 匯出自己的翻譯
- 批次匯入朋友分享的翻譯檔
- 設定不翻譯詞彙，保留伺服器名、品牌名或特殊名詞

翻譯包只會在你確認後下載，不會上傳你的模組清單或本機譯文。匯出的檔案也不包含 API Key、登入資料或模組設定。

## 六、它和現成中文化／RPMTW 有什麼不同？

NyanLex 並不是要取代人工中文化。

像 RPMTW 或各模組作者提供的繁中語言檔，優點是用詞經過整理，品質與一致性通常也會比即時翻譯穩定；有現成中文化時，我仍然推薦優先使用。

NyanLex 比較像是補上「還沒有人翻」和「內容會隨時改變」的部分：例如冷門模組、模組包任務、伺服器訊息、玩家聊天，以及當下畫面才出現的文字。玩家也能自行選擇 Google、雲端 AI 或本機模型，並把翻過的內容留在自己的快取中重複使用。

兩者方向不同：一邊是整理好的中文化資源，一邊是針對眼前內容的即時翻譯工具。對我來說，它們不是誰取代誰，而是解決不同情況。

## 八、安裝與第一次使用

1. 下載與 Minecraft 版本、Loader 完全相符的 JAR。
2. 把 JAR 放進該遊戲實例的 `mods` 資料夾；Fabric 版另外安裝 Fabric API。
3. 啟動遊戲，在第一次出現的快速設定中選擇目標語言與翻譯來源。
4. 完成確認後，再開始使用線上翻譯。

NyanLex 是純客戶端模組，不會修改伺服器，也不會代替玩家送出聊天訊息。

---

## 九、隱私與使用前提醒

這部分很重要，所以另外寫清楚：

- **新安裝時，線上翻譯預設關閉。** 只有玩家主動開啟後，文字才會送往選擇的翻譯服務。
- 翻譯聊天時，送出的內容可能包含私訊；請依自己使用的伺服器與服務商判斷是否開啟。
- Google 模式使用非官方網頁端點，可能被限流或失效。
- API Key 只存放在本機設定檔，設定畫面會遮罩顯示。
- 翻譯結果不保證完全正確。交易、伺服器規則或其他重要內容，建議保留原文一起確認。
- 不同模組的文字繪製方式差異很大，無法保證所有第三方介面都能完整翻譯或保留格式。
